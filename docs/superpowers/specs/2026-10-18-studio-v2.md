## Architecture and compatibility
Vanilla JavaScript + GrapesJS Pages API + JSZip. No new runtime dependency is required. Keep legacy buildDocument/export APIs and one-page tests compatible. Extend snapshots with optional studio metadata (schema 2); read schema 1 unchanged. Avoid overwriting the browser's existing saved project on upgrade. Restore checks apply to metadata, saved sections and history as well as editor project data.

Studio data contract: version 2; homeId; pages [{id,name,slug,title,description,nav,noindex}]; site {url,language,direction,socialImage,favicon,logo,brand:{paper,ink,accent,font,width,radius}}; assets [{id,name,src,alt}]; sections [{id,name,html}]; checkpoints [{id,name,savedAt,snapshot}] capped at five with nested checkpoints removed; autosave boolean. Page IDs must align with actual GrapesJS page IDs.

Core module contracts in src/site-model.js:
- createStudio(project, brief, input={}) reconciles editor pages and metadata, returns validated defaults.
- pageFile(meta, studio) returns index.html for home, otherwise slug.html.
- validateSlug(value, pages, excludeId) rejects reserved, unsafe and duplicate slugs.
- validateSiteUrl(value) accepts empty or public http/https URL without query/hash/credentials.
- brandCss(studio) produces shared portable CSS.
- navigationHtml(studio, currentId) produces escaped relative links and optional logo.
- rewriteNavigation(html, studio, currentId) replaces only generated site navigation, not unrelated links.

Export contracts: buildDocument({html,brief,page,studio,cssFile='styles.css'}) stays backward compatible; exportFiles(editor,brief,studio?) and siteZip(editor,brief,studio?) export all editor Pages when studio is supplied. Each page exports its own CSS (home styles.css; other slug.css) plus shared studio.css. Never select another editor page to export. Use getMainComponent then getHtml/getCss({component}). Include relative nav links, per-page metadata, favicon, canonical/OG, sitemap/robots/404 and README. Preview uses an iframe srcdoc with all files retained in memory and intercepts internal navigation inside the preview; no service worker or server required.
