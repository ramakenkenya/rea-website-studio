# Text Only catalog

Choose **Text Only** in **New website**. The original Rama Ken portfolio opens by default. Choose **Start with a blank page** to build the first page from scratch, or add a blank page from **Pages**.

## Sections

Open a group and click or drag a card onto the canvas. Edit the text in place. On the inspired blocks, **Section colors** in the inspector offers preset colors, light, dark, and light grid paper. Mix light and dark blocks to reproduce the alternating page treatment.

## Style

Select a heading, paragraph, or editable text element and apply Inset text, Outline, Reverse contrast, Editorial serif, Outline echo, Reflection, Vertical label, Oversized display, or Mono caption. The inset fields edit the small and large text separately. Vertical type reads horizontally on small screens.

## Picture to Text

Drag **Picture to Text** from **Start here**. The inspector selects the new artwork and shows **Choose a picture**. Upload a JPEG, PNG, or WebP, adjust crop, density, characters, and contrast, then choose **Apply text artwork**. The converted characters and description travel with the project and exported site.
